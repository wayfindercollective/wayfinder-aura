Run with `scripts/eval_matrix.py` on a Mac Studio (M3 Ultra, macOS 27),
through the app's own code: `transcribe_with_config()` on the resident
whisper-server and `process_with_config()` on the resident llama-server,
using the bundled binaries (whisper.cpp v1.9.1, llama.cpp b9608). Models are

## Styles (cleanup models)

22 samples × 5 styles × Standard/Strong, graded by `scripts/tone_eval`
metrics (word retention, order, new words, filler removal, slang/caps for
Professional, dev-term preservation, negation) and read by hand.
Grades: A ≥ 90 % pass, B ≥ 75 %, C ≥ 50 %, F below.

| Style | Gemma 3 1B | Qwen 3.5 2B | Qwen3 4B |
|---|---|---|---|
| Normal | C | A | A |
| Professional | F | F | C → A on reading; Strong A |
| Casual | C | C | A; Strong A |
| Dev | F | C | A; Strong A |
| Personal | C | C | A; Strong A |
| Latency (warm) | ~0.2 s | ~0.2 s | ~0.25–0.33 s |

Strong is capped to Standard for the 1–2B models by their size tier, so
only Qwen3 4B (or a cloud model) offers Strong.

What the grades mean in practice:

- **Gemma 3 1B changes meaning.** "diff" → "difference", "auth module" →
  "authentication module", "a couple more days" → "two more days", "or nah
  I'm pretty hungry" → "Yeah, I'm pretty hungry"; sometimes keeps "um".
- **Qwen 3.5 2B does almost nothing**: it returns the input, fillers and
  lowercase included.
- **Qwen3 4B is reliable.** Its Professional/Standard misses were sentence
  splitting and keeping "kinda" — fine on reading ("I'm going to refactor
  the auth module and rebase onto main before I merge…").

## End to end (speech model → cleanup model)

Each speech model's transcripts (22 samples, US voice) through every cleanup
cell: 7,260 cleanups. Real transcripts arrive punctuated and mostly
filler-free, so "do nothing" passes more often here than on raw text.

| Style | Gemma 3 1B | Qwen 3.5 2B | Qwen3 4B |
|---|---|---|---|
| Normal | C (token cap hit 47×) | A (174/242 unchanged) | A (242/242) |
| Professional | F | C | Standard C (sentence splits) · Strong A |
| Casual | F | A (by leaving text alone) | A |
| Dev | F | B | B (misses were speech errors, below) |
| Personal | F | A (by leaving text alone) | A |

- The app's hallucination guard did its job: 18 Qwen3 4B Professional
  Strong outputs were rejected and the text returned unchanged.
- Words said that survive to the final text: Qwen 3.5 0.87–0.93 (it barely
  edits), Qwen3 4B 0.77–0.83 (it edits: "gonna" → "going to"), Gemma
  0.73–0.77. The speech model moves this by only ~0.05.
- Dev "misses" were recognition errors, not cleanup: "git commit the
  boolean fix" heard as "get commit the bully and fix", "rebase" as
  "rebass", "auth module" as "off-module". The matrix transcribed with the
  neutral prompt; the Dev style primes Whisper with its word list:

| Speech model | Dev terms kept, neutral prompt | With the Dev word list |
|---|---|---|
| Base (EN) | 87% (WER 17.7%) | **93%** (WER 14.7%) |
| Large v3 Turbo Q5 | 96% (WER 8.5%) | **99%** (WER 9.8%) |

  Priming — and the user's own vocabulary and corrections — is what fixes
  the rest ("get hub -> GitHub", "bully and -> boolean").

## What changed because of this (branch `feature/styles-vocabulary`)

- **Normal** no longer uses a model: `normal_filler_removal()` removes filler
  sounds and accidental doubled small words in ~1 ms. On all 1,540
  transcripts above: 340 fillers → 1 (glued to a word by the speech model),
  no other word changed. The old `fast_filler_removal` regex deleted words
  that carry meaning ("turn right" → "turn", "do you know him" → "do him").
- **Styles grey out per model** (`STYLE_SUPPORT`): on Gemma 3 1B and Qwen 3.5
  2B only Normal is offered; the others say "try Qwen3 4B". Cleanup never
  runs a style the setup can't do (falls back to Standard, then Normal).
- Model descriptions and the Ultra copy say what was measured.

## Caveats

- One machine (M3 Ultra). Smaller Macs will be slower, especially Qwen3 4B
  (2.5 GB) and anything on CPU; re-run the speech stage on an M1/M2 Air
  before quoting speeds publicly.
- Synthetic voices are cleaner than real rooms and real mics.
- Linux's default cleanup path differs (llama-simple CLI; see
  LINUX-FOLLOWUPS §1.1) — re-run the style stage there.
