## Accepted residuals (known, disclosed, non-blocking)

- **Native-Wayland text injection in the Flatpak** is impossible by design
  (the sandbox forces X11; bundled xdotool targets X11/XWayland). Native and
  AppImage installs can inject on Wayland via host ydotool/wtype. Docs are
  scoped accordingly; the storefront is gate 4.
- **Adopted whisper-server mode is unknowable**: when the app adopts an
  already-listening server on its port instead of spawning one, that
  server's CPU/GPU mode can't be determined or changed and the server can't
  be killed by us. Reuse honestly refuses to match it after a mode flip, but
  a wrong-mode external server can persist until it exits. Adoption happens
  whenever a compatible server is already listening on the port (an orphan
  from a crash, or an externally started server); self-heals when that
  process exits.
- **Sleep/wake overlay recovery is disabled in the Flatpak** (needs
  dbus-python, deliberately not bundled). Pre-existing; logged at startup.
- **Portal consent limbo**: observed on the owner's Plasma 6.7 — dismissing
  the shortcut-approval dialog leaves shortcuts registered but inactive, and
  later launches did not re-prompt (the app calls BindShortcuts every
  launch; the no-reprompt is compositor-side behavior). Recovery is System
  Settings → Shortcuts. A future in-app cue (detect inactive bindings,
  offer ConfigureShortcuts) is the fix; not built.
- **Settings shows the configured style chord** while the compositor may
  bind a different one (owner chose F2 in KDE's dialog); under the portal
  model the compositor owns the binding. Cosmetic.
- `get_dynamic_tooltip` exists in two copies (root `wayfinder_main.py` and
  `src/wayfinder/ui/components.py`). This cycle unified their **warm-results
  filtering and seconds formatting**; the copies otherwise still diverge
  (GPU wording, extra dynamic sections in the root copy). Dedup deferred.
- KDE runtime 6.11 available; bump + rebuild-test at leisure.
- The owner's worktree root carries historical untracked AppImages; prune
  before any public-repo work (none are tracked at HEAD).
